Here’s a comprehensive list of **JavaScript interview questions** categorized by difficulty and topic, ideal for both freshers and experienced developers:

---

## 🟢 **Beginner-Level Questions**

### 🔤 Basics
- What are the different data types in JavaScript?
- What is the difference between `var`, `let`, and `const`?
- Explain hoisting in JavaScript.
- What is the difference between `==` and `===`?
- What are truthy and falsy values?
- What are template literals?

### 🔁 Control Flow
- What is the difference between `for`, `while`, and `do...while` loops?
- How does `switch` work in JavaScript?

### 🔄 Functions
- How do you declare a function in JavaScript?
- What are arrow functions and how are they different from regular functions?
- What is a callback function?

### 🔃 Array & Object Manipulation
- What are common array methods (`map`, `filter`, `reduce`, `forEach`) and how do they work?
- How to clone an object in JavaScript?
- How to merge two arrays or objects?

---

## 🟡 **Intermediate-Level Questions**

### ⚙️ Scope and Closures
- What is lexical scope?
- What is a closure and how is it used?

### 🧵 Asynchronous JavaScript
- What is the event loop in JavaScript?
- What are Promises and how do they work?
- Difference between `async/await` and Promises?
- What is the use of `setTimeout`, `setInterval`?

### 🧱 DOM Manipulation
- What is the DOM?
- How to select and manipulate DOM elements using JavaScript?
- Difference between `innerHTML`, `textContent`, and `innerText`?

### 🧪 Error Handling
- What is the difference between `try/catch/finally` and `.catch()` in promises?
- How to handle errors in async/await?

---

## 🔴 **Advanced-Level Questions**

### ♻️ Object-Oriented JavaScript
- What is the prototype chain?
- How does inheritance work in JavaScript?
- Difference between `Object.create()` and class-based inheritance?
- What are ES6 classes?

### 🏗️ Functional Programming
- What is a pure function?
- What is immutability?
- What is the difference between `map`, `reduce`, and `forEach`?

### 🔐 JavaScript Runtime and Engine
- How does the JavaScript engine work?
- What are call stack, heap, and memory leaks?

### 📦 Modules
- What is the difference between `require` and `import`?
- What are ES modules and CommonJS modules?

### 🔄 Event Handling
- What is event delegation?
- What are event bubbling and capturing?

### 📤 Browser & Networking
- What are CORS and how does it work?
- What is the difference between `localStorage`, `sessionStorage`, and `cookies`?
- How do you make an HTTP request in JavaScript?

---

## 🧪 **Tricky / Coding-Based Questions**

- Flatten a nested array.
- Deep clone an object.
- Implement a debounce and throttle function.
- Write a polyfill for `bind`, `call`, or `Promise.all`.
- Reverse a string without using built-in methods.
- Create a simple promise-based retry mechanism.
